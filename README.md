# MangaForge Studio — أنمي قصير كل يوم، وحلقة كاملة كل أسبوع

مقطع **~2 دقيقة كل يوم** (أفقي + عمودي للـShorts) ← بعد 7 أيام تُدمج المقاطع في **حلقة واحدة** تلقائياً، كل ذلك على GitHub Actions المجاني.
القصة والشخصيات من **مانغا حقيقية** تُجلب مباشرة من MangaDex (تُختار الأقرب إلى Demon Slayer)، والرسم بخدمة مفتوحة مجانية (AI Horde)،
والتحريك والمؤثرات في **Blender**، ثم مونتاج وصوت وترجمة عربية سليمة.

## ما الذي ستحصل عليه فعلاً — بصدق

| ✔ ما يقدّمه المشروع | ✘ ما لا يقدّمه |
|---|---|
| مقطع مُخرَج بإيقاع قتال (قطعات سريعة، لقطات اصطدام بيضاء، انتقالات سريعة، تباطؤ/تسريع، أسماء التقنيات) | أنمي من مستوى Ufotable أو فيديو نموذج ذكاء اصطناعي: لا يمكن ذلك تلقائياً على معالجات مجانية بلا كرت شاشة |
| كل لقطة صورة مرسومة **تتحرك في العمق** (باراللاكس حقيقي من خريطة عمق)، كاميرا سينمائية، عمق ميداني، ضبابية حركة | شخصيات ثلاثية الأبعاد بهياكل عظمية (هذا ألغيناه بقرارك: 2.5D + لمسات 3D في القتال) |
| **مؤثرات 3D حقيقية في بلندر**: موجات صدمة، شرر، حطام، برق، قطع السيف، أوراق/بتلات تتحرك فردياً، ضباب، مطر، ثلج | لقطات تحريك كامل للشخصية (المشي، الملاكمة…) بدون نموذج فيديو |
| **العيون**: كشف، رمش، حركة نظر، لمعة، توهج، دموع، لقطات قريبة للعين | تحريك الفم |
| ترجمة عربية مُشكَّلة صحيحاً (لا حروف مقطّعة) + صوت (VOICEVOX ← edge-tts) | |
| **اختياري:** تحريك فعلي للقطات البطولة بنموذج فيديو (ComfyUI + LTX/Wan) إن توفر لديك كرت شاشة — راجع `assets/workflows/README.md` | |

**صدق الاختبار:** كل الشيفرة مُختبَرة (200+ اختبار) ورُندر عرض تجريبي كامل بمحرك OpenCV، وأما شيفرة Blender فاختُبرت أمام محاكٍ دقيق لواجهة `bpy`
(يتحقق من أسماء العقد والحقول واتجاه الروابط والتسلسل) **ولم تُشغَّل في Blender حقيقي** — لذلك أول خطوة لك هي تشغيل `selftest` (دقيقة واحدة، أدناه).
كذلك لم تُجرَّب الخدمات الحيّة (AI Horde وGemini وMangaDex وVOICEVOX) لأن بيئة التطوير بلا إنترنت لها.

## التشغيل على GitHub (الطريقة الموصى بها)

1. أنشئ مستودعاً **عاماً** (Public: الدقائق مجانية بلا حد) وارفع هذا المجلد كاملاً.
2. **Settings → Secrets and variables → Actions → Secrets**: أضف
   - `GEMINI_API_KEY` (مجاني من aistudio.google.com — القصة والتحليل البصري؛ يمكن `_2` و`_3`)
   - اختياري: `HORDE_API_KEY` (طابور أسرع)، `CF_ACCOUNT_ID` + `CF_API_TOKEN`، `POLLINATIONS_KEY`
   - للرفع على يوتيوب: `YT_CLIENT_ID` و`YT_CLIENT_SECRET` و`YT_REFRESH_TOKEN` (من Google Cloud → YouTube Data API v3 → OAuth؛ بدونها يُنتج الفيديو ولا يُرفع).
3. **Actions → selftest → Run workflow** — *افعل هذا أولاً.* يشغّل الاختبارات ثم **Blender حقيقياً** بعرض تجريبي، و`RENDER_STRICT=1` يجعل أي فشل في Blender ظاهراً بدل التراجع الصامت.
   في نهايته قائمة بكل ميزة من ميزات Blender: `ok` / `off` / `skipped:<سبب>` / `failed:<خطأ>`، ومقطع تجريبي في Artifacts. **أرسل لي أي `failed` وأصلحه.**
4. **Actions → daily-short → Run workflow** (مرة يدوية لترى النتيجة). بعدها يعمل وحده كل يوم 01:17 UTC.
5. ضبط اختياري عبر **Variables** (اسم المتغير = اسم الإعداد في `.env.example`): `SHARDS` (عدد الأجهزة، 8)، `CYCLES_SAMPLES` (24)، `BLENDER_SERIES` (4.5)، `STORY_SOURCE`، `MANGA_ID`…

### كيف يتجاوز حد الـ6 ساعات
كل مرحلة قابلة للاستئناف وتحفظ تقدّمها: القصة والصوت والصور في cache، وكل **رسمة** مرندرة تُحفَظ، وكل لقطة منتهية لها بصمة (الخطة + محتوى الصور + المحرك + الدقة).
عند اقتراب 5.4 ساعة يتوقف الرندر بنظافة (رمز خروج 3) ويبدأ مهمة `restart` تشغيلاً جديداً يكمل من حيث توقف (حتى `MAX_ATTEMPTS`=12). لا شيء يُعاد رسمه إلا إن تغيّرت الخطة.

### ماذا يُنتَج
- `short_<job>.mp4` (أفقي) و`short_<job>_vertical.mp4` (9:16) + صورة مصغّرة، تُرفع إلى يوتيوب (إن وُجدت المفاتيح) وتُحفظ كـ **Release**.
- بعد المقطع السابع: `weekly-episode` يدمج السبعة في `episode_NN.mp4` بعنوان وفصول ويرفعه.
- `state/series.json` يُحفظ في المستودع بعد كل يوم (الحلقة/الجزء، القصة، الشخصيات).

## التشغيل على جهازك
```bash
pip install -r requirements.txt            # + torch (CPU) لخريطة العمق
python -m mangaforge doctor --blender      # فحص التثبيت + اختبار Blender
python -m mangaforge selftest              # لقطة صغيرة عبر Blender الحقيقي
python -m mangaforge demo --engine cv --seconds 12     # عرض كامل بلا مفاتيح
python -m mangaforge short                 # مقطع اليوم كاملاً (قصة ← صوت ← رسم ← رندر ← مونتاج)
python -m mangaforge prepare ; python -m mangaforge render --shard 0/4 ; python -m mangaforge assemble   # على مراحل
python -m mangaforge weekly                # دمج أسبوع
python -m mangaforge features [--job e01p1]    # خريطة صادقة لكل ميزات Blender المئة ← ما هو منفَّذ وما هو بديل وما هو غير منفَّذ
```
**Blender**: ثبّت 4.2 LTS أو أحدث (يدعم حتى 5.x) وضع المسار في `BLENDER_BIN`. بدونه يعمل محرك OpenCV 2.5D البديل تلقائياً.

## المانغا والقصة
`STORY_SOURCE=manga` (الافتراضي): يختار المشروع من MangaDex عنواناً قريباً من `MANGA_LIKE=Kimetsu no Yaiba` (بالوسوم) وفيه فصول قابلة للقراءة،
يقرأ الصفحات بنموذج الرؤية ويحوّلها إلى سيناريو مقاطع. للتحكم: `MANGA_ID=<uuid>` أو `MANGA_TITLE=...`. `STORY_SOURCE=original` لقصة مخترعة.
المقطع الأول (`PILOT=1`) يحصل على افتتاح وبطاقة عنوان وخطّاف.

> **حقوق النشر:** اقتباس مانغا منشورة وتحويلها إلى فيديو يُحقَّق منه دخل يحتاج **إذناً من أصحاب الحقوق**. يضيف المشروع الاعتمادات تلقائياً لكن هذا لا يغني عن الإذن.
> استخدم أعمالاً مرخّصة للاقتباس (مثلاً بإذن المؤلف) أو `STORY_SOURCE=original` للتحقق من المونيتيزيشن.

## العيون (ميزة أساسية)
كشف العينين بنموذج الرؤية ← تحليل (لون/شكل) ← طبقات RGBA لكل عين + خطة حركة (رمش، نظرات سريعة، تمدد البؤبؤ، لمعة، توهج، دموع) ← تُخبَز كرقع صور وتُعرض على مجسمات عميقة في Blender (ومباشرة في محرك OpenCV).
`EYES=1` افتراضياً؛ `EYE_REFINE=1` يطلب تمريرة تحسين لوجوه اللقطات القريبة (يتطلب مزوداً يدعم img2img: ComfyUI/A1111).

## تحريك AI اختياري (أقرب مظهر للفيديو المرجعي)
يحتاج GPU: شغّل ComfyUI مع LTX-Video/Wan (جهازك، Colab، RunPod…) واتبع `assets/workflows/README.md`. `I2V_BACKEND=comfyui`.
لقطات البطولة (الضربات، القتال، القريبة، الافتتاح) تتحرك بالنموذج ويضيف Blender فوقها الكاميرا والتأثيرات والتدريج.

## الإعدادات
كل الإعدادات متغيرات بيئة مع قيمها الافتراضية في **`.env.example`** (على GitHub: Variables). أهمها: `SHARDS`، `CYCLES_SAMPLES`، `RENDER_SCALE` (0.5 للمسودات)،
`PHYSICS_FX=1` (دخان/نار Mantaflow وقماش حقيقي)، `VOLUMETRICS=1`، `SAVE_BLEND=1` (ملف .blend لكل لقطة لتحسينه يدوياً)، `VIEW_TRANSFORM`، `I2V_*`، `MANGA_*`.

## حل المشكلات
| العَرَض | الحل |
|---|---|
| `selftest` يفشل في ميزة | انسخ سطر `failed:` من التقرير؛ الميزة تُتخطّى والمقطع يكمل (`RENDER_STRICT=0`) |
| صوت صامت | شغّل VOICEVOX أو ثبّت `edge-tts` (الأخير يحتاج إنترنت) |
| صور بديلة بدل الرسم | لا مزود صور متاح؛ تحقق من `HORDE_API_KEY` أو شغّل ComfyUI؛ `ALLOW_PLACEHOLDER_ART=0` يوقف بدل أن يُنتج بديلاً |
| ترجمة مربعات □ | الخطوط تُثبَّت في الـworkflow (Noto)؛ محلياً ثبّت `fonts-noto-core fonts-noto-cjk` أو ضع خطاً في `assets/fonts/` |
| المهمة توقفت عند 6 ساعات | طبيعي: تبدأ `restart` وحدها وتكمل؛ زِد `SHARDS` لتسريع الرندر |

## بنية المشروع
`mangaforge/` — `story` `manga` (القصة) · `voice` · `art/` (مزودو الصور، الطبقات، العمق) · `eyes` `eye_anim` (العيون) · `director` (الخطة والإيقاع) ·
`render/` (محرك Blender: `blender_scene` `blender_fx` `blender_extras` · محرك OpenCV: `cv_engine` · `features`) · `post` (ffmpeg) · `sound` `subs` · `assemble` · `publish` · `lineart` (تتبع حبر المانغا — غير موصول بعد) · `i2v`.
`tests/` — الاختبارات (محاكي bpy في `fake_bpy.py`). `.github/` — workflows. `SPEC.md` — العقد الداخلي.
